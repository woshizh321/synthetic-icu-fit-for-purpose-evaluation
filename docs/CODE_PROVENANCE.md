# Code provenance

The current evaluation kernels are public-safe copies of the executed scientific implementation. The release adaptations are limited to input/output paths, package imports, reference-function extraction and documentary labels. Mathematical functions, optimizer settings, DGP transformations, seed construction and metric formulas are preserved.

The current renderer flattens the executed display script's source reuse into a standalone program. It changes argument/output plumbing, not scientific values or geometry. Source CSVs and final figure binaries are copied unchanged from the authoritative final displays. Their hashes are listed in the release manifest.

Clinical extraction, generation and utility helper modules provide bounded source-pipeline interfaces and fabricated tests. They do not distribute restricted records or establish complete historical source replay. Compatibility API names for realized internal/external performance gaps are not manuscript endpoint claims. See ESTIMANDS.md and REPRODUCIBILITY.md.
