# Public release scope

Approved: public software/configuration; historical V2 and final R2 manuscript-facing figures; aggregate source CSVs for tables and displays; Supplementary Data 1–10; the minimal simulated replicate-level P95 input required for E3/E5 reproduction; E1 aggregate decision-translation verification; fabricated examples and tests. Aggregate and simulated files contain neither patient-level records nor source hospital identifiers. Empirical model summaries describe populations/templates, not individual hospitals.

Excluded: row-level clinical or evaluated synthetic data, patient predictions, fitted clinical models, private resampling/linkage/covariance assets, source hospital identifiers or hospital-indexed restricted derivatives, private project records, manuscript text/drafts, correspondence, temporary files and obsolete result assets.

The root release manifest describes released payload files with SHA-256, size, class and approval status. A checksum manifest cannot hash itself; its own digest and the immutable release commit are recorded in the external release verification. Historical tags/releases and archive versions remain unchanged.

Original code is MIT; released aggregate/simulated results, figures, Supplementary Data and documentation retain CC BY 4.0. Upstream and clinical-data terms remain separate. No third-party clinical data are redistributed. The archive retains its established dataset resource type and stable concept DOI.
