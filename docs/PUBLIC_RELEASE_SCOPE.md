# Public release scope

Approved: public software/configuration; final manuscript-facing figures; aggregate source CSVs for main tables, displays and safe supplementary electronic tables; fabricated examples and tests. Aggregate files contain neither patient-level records nor source hospital identifiers. Empirical model summaries describe populations/templates, not individual hospitals.

Excluded: row-level clinical or evaluated synthetic data, individual predictions, fitted clinical models, private resampling/linkage assets, source hospital-specific restricted derivatives, private project records, manuscript text/drafts, correspondence, temporary files and obsolete result assets.

The root release manifest describes released payload files with SHA-256, size, class and approval status. A checksum manifest cannot hash itself; its own digest and the immutable release commit are recorded in the external release verification. Historical tags/releases and archive versions remain unchanged.

Original code is MIT; released aggregate results and documentation retain CC BY 4.0. Upstream and clinical-data terms remain separate. The archive retains its established dataset resource type and stable concept DOI.
