# Supplementary Data inventory

These files accompany the R2 manuscript candidate. They are not yet present in the public v1.3.0 GitHub/Zenodo archive.

- Supplementary Data 1: E1 real-trained AUROC (Supplementary_Data_01_E1A_REAL_TRAINED_BASELINE_AUROC.csv)
- Supplementary Data 2: E1 realization-level EUL summary (Supplementary_Data_02_E1B_REALIZATION_EUL_SUMMARY.csv)
- Supplementary Data 3: E1 empirical M1/M2/M3 decisions (Supplementary_Data_03_E1C_EMPIRICAL_M1_M2_M3_P95_DECISIONS.csv)
- Supplementary Data 4: E1 M4 realization decisions (Supplementary_Data_04_E1D_M4_REALIZATION_DECISIONS.csv)
- Supplementary Data 5: E1 hospital-population decisions (Supplementary_Data_05_E1E_H100_H200_H300_M1_TARGETB_DECISIONS.csv)
- Supplementary Data 6: E3 frozen cost grid (Supplementary_Data_06_E3_COST_GRID.csv)
- Supplementary Data 7: E3 scenario-conditional regret results (Supplementary_Data_07_E3_CONDITIONAL_REGRET_RESULTS.csv)
- Supplementary Data 8: E3 paired strategy contrasts (Supplementary_Data_08_E3_PAIRED_STRATEGY_CONTRASTS.csv)
- Supplementary Data 9: E3 fixed-P95 sensitivity (Supplementary_Data_09_E3_FIXED_P95_SENSITIVITY.csv)
- Supplementary Data 10: E5 complete leave-one-generator-out results (Supplementary_Data_10_E5_LEAVE_ONE_GENERATOR_OUT_RESULTS.csv)

Supplementary Data 8 preserves the source `comparison_label` and adds R2 fields distinguishing exact [0,0] zero-variance contrasts from uncertain intervals containing zero.
