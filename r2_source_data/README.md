# R2 figure source data

These privacy-cleared aggregate tables drive `reproduction/reproduce_r2_figures.py`.

- `E1A`, `E1C`, `E1D`, and `E1E` files support the empirical context and decision-instability panels.
- `V2_FIGURE2`, `V2_FIGURE3`, and `V2_FIGURE4` preserve the locked original simulation profiles, paired contrasts, and coverage summaries.
- `E3_CONDITIONAL_REGRET_RESULTS.csv`, `E3_PAIRED_STRATEGY_CONTRASTS.csv`, and `E5_LEAVE_ONE_GENERATOR_OUT_RESULTS.csv` support the cost and generator-composition panels.

Main-table inputs remain in `manuscript_source_data/TABLE1A_SOURCE_DATA.csv` through `TABLE3_SOURCE_DATA.csv`. Supplementary Data 1–10 are in `supplementary_data/`.

All files are aggregate or simulated. No patient, encounter, or source-hospital identifier is present.
